# Web Development Fundamentals

## Course Summary
This 1-hour course introduces high school students to creating simple websites with HTML and CSS.

- **Total Duration**: ~60 minutes
- **Target Audience**: Students aged 12 to 17
- **Prerequisites**: None
- **Required Tools**: Web Browser only (Chrome, Firefox, Safari, Edge)
- **Source Code Repository**: [GitHub Link](https://github.com/TopGlobals/webdev-course-topglobals)

## Project Structure
- `/starter-files`: Code templates for student practice
- `/completed-examples`: Finished solution code for lessons
- `/scripts`: Auxiliary scripts or tools

## Lesson Sequence
- **Lesson 1**: What is Web Development? 
- **Lesson 2**: Introduction to HTML
- **Lesson 3**: Adding More HTML Elements
- **Lesson 4**: Introduction to CSS
- **Lesson 5**: Creating a Simple Webpage
- **Lesson 6**: Tips and Next Steps
