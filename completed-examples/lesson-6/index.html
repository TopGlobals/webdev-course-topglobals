Recomendaciones y Errores Comunes

Aprende a reconocer, depurar y evitar los fallos más habituales en HTML y CSS.

1. Etiquetas no cerradas o mal anidadas

Error Frecuente

<p>Texto <strong>importante</p>

El navegador intenta corregir la etiqueta faltante, lo cual desconfigura el diseño.

Buena Práctica

<p>Texto <strong>importante</strong></p>

Cierra siempre las etiquetas en el orden inverso en que las abriste.

2. Omitir el atributo alt en imágenes

Error Frecuente

<img src="foto.jpg">

Afecta la accesibilidad web: los lectores de pantalla no pueden describir la imagen.

Buena Práctica

<img src="foto.jpg" alt="Foto de perfil de estudiante">

Incluye siempre una descripción textual breve y concisa.

3. Olvidar el punto y coma (;) en declaraciones CSS

Error Frecuente

color: blue
font-size: 16px;

Sin el punto y coma, el navegador descarta por completo la siguiente propiedad.

Buena Práctica

color: blue;
font-size: 16px;

Finaliza siempre cada par propiedad-valor con un punto y coma (;).

Lista de Verificación y Próximos Pasos

  • Valida siempre tu código con el Validador de la W3C.
  • Consulta documentación oficial y actualizada en MDN Web Docs.
  • Utiliza la tecla F12 del navegador para inspeccionar elementos y ver estilos aplicados en vivo.
